# Ethics & Scope Statement

This project is a **defensive security (blue-team) portfolio lab**, operated under the rules below.

## Authorization
- All testing is performed only on infrastructure and accounts I own or am explicitly authorized to use.
- The simulated phishing campaign targets only my own seed email accounts. No third party is ever targeted or contacted.

## Simulation vs. real activity
- Phishing emails generated by this lab use a **fictional organization ("Acme Corp")**. No real company, brand, logo, or domain is impersonated.
- Real phishing samples analyzed here were received unsolicited in my own mailboxes. They are analyzed as evidence; their malicious links and infrastructure are never visited or re-used.

## Handling of malicious material
- Captured attachments are treated as live malware: analyzed **statically only** (hashing, string inspection) and **never executed**.
- Malware samples, raw emails, and extracted indicators are **excluded from version control** (see `.gitignore`) and never published.
- All indicators of compromise (IOCs) in documentation are **defanged** (e.g., `hxxp://bad[.]site`).

## Data privacy
- Email addresses, personal data, and internal identifiers in samples are redacted before anything is published.
- API keys and credentials are stored locally in `secrets/` and never committed.

## Purpose
This lab demonstrates practical SOC analyst skills — phishing triage, IOC enrichment, detection engineering, and incident response — in a controlled, ethical, and reproducible way.
